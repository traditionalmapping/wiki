# Traditional Mapping Wiki

[English](README.md) | **Русский**

Интерактивная карта с видео, привязанными к местам. Видео отображаются в двух местах:

- в виде **панелей на карте**, указывающих на место
- в **списке «Videos» слева**, у каждого видео есть кнопка **Show on map**

## Как добавить видео

Все видео хранятся в одном файле: **`js/places.js`**. Другие файлы трогать не нужно.

### 1. Получите координаты

1. Откройте карту и сдвиньте её так, чтобы **белый крестик** в центре экрана оказался точно на нужном месте.
2. Нажмите **Copy** в блоке координат справа вверху.
3. Теперь у вас есть координаты в формате `широта, долгота`, например `52.22970, 21.01220`.

### 2. Добавьте новое место

Откройте `js/places.js`, скопируйте целый блок `{ ... }` и вставьте его после последнего. Между блоками должна стоять запятая.

```js
{
  coords: '52.22970, 21.01220',
  videos: [
    { title: 'Название видео', url: 'https://www.youtube.com/watch?v=XXXXXXXXXXX' }
  ]
},
```

| Поле     | Что указать                                         |
|----------|-----------------------------------------------------|
| `coords` | Вставьте координаты, скопированные кнопкой **Copy** |
| `title`  | Название, которое видно на панели и в списке        |
| `url`    | Ссылка на видео                                     |

### 3. Добавьте ещё видео к существующему месту

Добавьте ещё строки `{ title, url }` в список `videos` этого места, разделяя их запятыми.

```js
videos: [
  { title: 'Первое видео', url: 'https://www.youtube.com/watch?v=AAAAAAAAAAA' },
  { title: 'Второе видео', url: 'https://www.youtube.com/watch?v=BBBBBBBBBBB' }
]
```

Панель на карте показывает первое видео и кнопку **+N**, которая открывает остальные. Список слева показывает все видео.

### Превью (миниатюры)

- **Ссылки YouTube:** превью создаётся автоматически.
- **Другие сайты:** добавьте `thumb` к этому видео:

```js
{ title: 'Моё видео', url: 'https://example.com/video', thumb: 'https://example.com/image.jpg' }
```

### Дополнительно: дата, теги, название места (автор определяется сам)

Панель **Videos** слева умеет искать, группировать, сортировать и фильтровать. Для этого используются дополнительные поля (все необязательные):

```js
{
  coords: '52.22970, 21.01220',
  name: 'Warsaw',                       // название места (для «Group by: Place»)
  videos: [
    {
      title: 'Warsaw Uprising (1944)',
      url: 'https://www.youtube.com/watch?v=XXXXXXXXXXX',
      date: '1944-08-01 / 1944-10-02',  // когда происходят события в видео
      tags: ['Eastern Front', 'Every day']  // кликабельные метки и фильтр Tag
    }
  ]
},
```

- **Автор:** для ссылок YouTube название канала определяется автоматически (и запоминается в браузере), писать его не нужно. Можно всё же указать `author: '...'`, чтобы переопределить, а для ссылок с других сайтов он нужен.
- **Дата:** дата событий, показанных в видео, а не дата загрузки. Можно одну дату или период: `'1944-08-01'`, `'1944-08'`, `'1944'` или `'1944-08-01 / 1944-10-02'`. Группировка по годам и сортировка используют дату начала. Автоматически её определить нельзя, укажите вручную.
- **Теги** и **название места** тоже пишутся вручную.

Видео без даты попадают в группу «Unknown date», а при сортировке по дате идут в конце. Фильтр **Tag** появляется, когда хотя бы у одного видео есть тег.

### Просмотр видео

Клик по **превью YouTube** открывает видео во всплывающем окне прямо на странице с картой, переходить на YouTube не нужно. Закрыть можно крестиком ✕, кликом вне окна или клавишей **Esc**. Ctrl/Shift-клик (или средняя кнопка мыши) откроет YouTube в новой вкладке. Ссылки с других сайтов всегда открываются в новой вкладке.

Если владелец видео запретил встраивание, YouTube не сможет воспроизвести его во всплывающем окне. Такое видео определяется автоматически, и его превью открывает YouTube в новой вкладке. Это можно включить и вручную, добавив к видео `embed: false`.

> Плееру нужно, чтобы сайт открывался по `http://` или `https://` (например, через GitHub Pages или локальный сервер). Если открыть страницу напрямую как `file://`, YouTube покажет ошибку вместо видео.

## Частые ошибки

- **Пропущена запятая** между двумя блоками `{ ... }` или двумя видео. Если в файле синтаксическая ошибка, ничего не отобразится.
- **Координаты в неверном порядке.** Нужно `широта, долгота` (кнопка Copy уже выдаёт их в таком порядке).
- **Ссылка без `https://`.** Принимаются только обычные веб-ссылки.
- **В браузере ничего не изменилось.** Обновите страницу (Ctrl+F5), чтобы сбросить кэш.

Если место не появилось, откройте консоль браузера (F12). Там будет предупреждение, например `Place #3: bad coords`.
