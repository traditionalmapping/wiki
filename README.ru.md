# Traditional Mapping Wiki

[English](README.md) | **Русский**

Интерактивная карта с видео, привязанными к местам. Видео отображаются в двух местах:

- в виде **панелей на карте**, указывающих на место
- в **списке «Videos» слева**, у каждого видео есть кнопка **Show on map**

## Как добавить видео

Все видео хранятся в одном файле: **`js/places.js`**. Другие файлы трогать не нужно.

### 1. Получите координаты

1. Откройте карту и сдвиньте её так, чтобы **белый крестик** в центре экрана оказался точно на нужном месте.
2. Нажмите **Copy** в блоке координат справа вверху.
3. Теперь у вас есть координаты в формате `широта, долгота`, например `52.22970, 21.01220`.

### 2. Добавьте новое место

Откройте `js/places.js`, скопируйте целый блок `{ ... }` и вставьте его после последнего. Между блоками должна стоять запятая.

```js
{
  coords: '52.22970, 21.01220',
  videos: [
    { title: 'Название видео', url: 'https://www.youtube.com/watch?v=XXXXXXXXXXX' }
  ]
},
```

| Поле     | Что указать                                         |
|----------|-----------------------------------------------------|
| `coords` | Вставьте координаты, скопированные кнопкой **Copy** |
| `title`  | Название, которое видно на панели и в списке        |
| `url`    | Ссылка на видео                                     |

### 3. Добавьте ещё видео к существующему месту

Добавьте ещё строки `{ title, url }` в список `videos` этого места, разделяя их запятыми.

```js
videos: [
  { title: 'Первое видео', url: 'https://www.youtube.com/watch?v=AAAAAAAAAAA' },
  { title: 'Второе видео', url: 'https://www.youtube.com/watch?v=BBBBBBBBBBB' }
]
```

Панель на карте показывает первое видео и кнопку **+N**, которая открывает остальные. Список слева показывает все видео.

### Превью (миниатюры)

- **Ссылки YouTube:** превью создаётся автоматически.
- **Другие сайты:** добавьте `thumb` к этому видео:

```js
{ title: 'Моё видео', url: 'https://example.com/video', thumb: 'https://example.com/image.jpg' }
```

## Частые ошибки

- **Пропущена запятая** между двумя блоками `{ ... }` или двумя видео. Если в файле синтаксическая ошибка, ничего не отобразится.
- **Координаты в неверном порядке.** Нужно `широта, долгота` (кнопка Copy уже выдаёт их в таком порядке).
- **Ссылка без `https://`.** Принимаются только обычные веб-ссылки.
- **В браузере ничего не изменилось.** Обновите страницу (Ctrl+F5), чтобы сбросить кэш.

Если место не появилось, откройте консоль браузера (F12). Там будет предупреждение, например `Place #3: bad coords`.

## Файлы

| Файл                | Назначение                                           |
|---------------------|------------------------------------------------------|
| `js/places.js`      | **Список мест и видео (редактируйте этот файл)**     |
| `js/markers.js`     | Рисует панели на карте и список видео слева          |
| `js/map.js`         | Настройка карты и элементы управления                |
| `js/menu.js`        | Меню периодов                                        |
| `js/history.js`     | Историческая карта и ползунок прозрачности           |
| `css/style.css`     | Все стили                                            |
| `index.html`        | Структура страницы и меню периодов                   |
